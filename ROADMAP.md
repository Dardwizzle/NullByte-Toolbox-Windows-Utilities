## NullByte Toolbox — Future Tools Roadmap

This roadmap outlines planned utilities that will expand the NullByte Toolbox into a full suite of Windows power‑tools. Each tool is designed to be lightweight, safe, and focused on solving a specific problem cleanly. This list is subject to change without notice. This should be viewed as a brainstorming excersize as some tools may be added and some may be removed.

---

### 🔧 **1. NullByte Process Sentinel**
A lightweight watchdog that monitors system responsiveness and identifies:
- Hung processes  
- Memory‑leaking apps  
- GPU stalls  
- Browser tab runaway processes  

**Planned features:**
- Auto‑terminate rules  
- “Quarantine mode” for suspicious processes  
- CSV/JSON export  
- Optional GUI dashboard  

---

### 🧹 **2. NullByte Hazmat Mode**
A deep‑clean utility for:
- Temp files  
- Windows Update leftovers  
- Browser caches  
- Crash dumps  
- Orphaned installer files  

**Planned features:**
- Safe mode (preview only)  
- Aggressive mode (full purge)  
- Cleanup profiles  
- Scheduled cleanup  

---

### 🖥️ **3. NullByte Display Doctor**
A tool for fixing common display issues:
- Stuck HDR  
- Washed‑out colors  
- Incorrect ICC profiles  
- DPI scaling glitches  
- Window ghosting after sleep  

**Planned features:**
- One‑click “Reset Display Pipeline”  
- ICC profile backup/restore  
- HDR toggle hotkeys  
- Multi‑monitor layout lock  

---

### 🌐 **4. NullByte Network Resetter**
A modern replacement for the classic “netsh reset” scripts.

**Capabilities:**
- Reset Winsock  
- Flush DNS  
- Reset network adapters  
- Clear Wi‑Fi profiles  
- Rebuild network stack  

**Planned features:**
- Verbose diagnostics  
- Exportable network report  
- Auto‑repair mode  

---

### 🎮 **5. NullByte Game Mode Booster**
A gaming‑focused utility that:
- Kills known background hogs  
- Disables overlays  
- Prioritizes GPU/CPU for the active game  
- Clears shader caches (optional)  

**Planned features:**
- Per‑game profiles  
- FPS stability mode  
- Auto‑optimize on game launch  

---

### 🔐 **6. NullByte Privacy Guard**
A privacy‑focused tool for:
- Clearing MRU lists  
- Clearing recent files  
- Clearing Run dialog history  
- Clearing Explorer search history  
- Clearing clipboard history  

**Planned features:**
- “Stealth Mode” (auto‑clear on shutdown)  
- Custom wipe lists  
- Secure wipe option  

---

### 🗂️ **7. NullByte QuickBackup**
A simple, fast backup utility for:
- Config folders  
- Save games  
- App settings  
- Browser profiles  
- Scripts and tools  

**Planned features:**
- One‑click backup  
- One‑click restore  
- Cloud‑sync optional  
- Backup versioning  

---

### 🧪 **8. NullByte Diagnostics Suite**
A collection of micro‑tools:
- Disk speed test  
- RAM integrity quick‑check  
- CPU thermal snapshot  
- GPU load snapshot  
- System health summary  

**Planned features:**
- Exportable diagnostics report  
- “Share with support” mode  
- Auto‑detect common failure patterns  

---

### 🧰 **9. NullByte Toolbox Launcher**
A unified launcher for all NullByte tools.

**Planned features:**
- Tool categories  
- Search bar  
- Update checker  
- Plugin support  
- Theming (NullByte Dark, NullByte Neon, NullByte Terminal)  

---

### 🧿 **10. NullByte Watchdog (Background Service)**
A lightweight background service that:
- Monitors system health  
- Detects runaway processes  
- Alerts when RAM/GPU spikes  
- Suggests tools from the toolbox  

**Planned features:**
- Silent mode  
- Notification mode  
- Auto‑action mode  
- Integration with Process Sentinel
